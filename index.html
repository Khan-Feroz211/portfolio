QARD

Pakistan's first multi-tenant virtual student ID SaaS

Students get verified digital IDs on their phones via a React Native iOS/Android app. Universities get a full admin portal to manage enrollment, verification, and benefits. FAISS-powered face verification eliminates fake ID fraud. Multi-tenant architecture with each university fully isolated with its own branding and admin panel.

  • 500+ students across 5+ universities using verified digital IDs
  • 50+ ID requests processed per week
  • Eliminated physical ID queues across multiple campuses
  • Pakistan's first platform of its kind
  • 99.5% uptime with Kubernetes auto-scaling
